# TAFE SAT practice scoring

Each scored form has a versioned practice conversion table for Reading and Writing and for Math. Each section table contains one score per possible correct-answer count, starting at zero. The two section scores are added to produce the total. Wrong and blank answers both contribute zero correct answers and are counted separately. Accuracy divides correct answers by all graded questions, including blanks.

The initial full practice form uses 55 Reading and Writing entries for 54 questions and 45 Math entries for 44 questions. Version 1 is an editorial, nonlinear TAFE curve. The exact tables are seeded in the `sat_score_reports` migration. It is a fixed-form practice estimate with 200–800 per section and 400–1600 in total. The four report bands are TAFE labels at 400, 1000, 1200, and 1400. They convey practice performance without implying percentiles, College Board benchmarks, or predictive validity. College Board's digital assessment uses an adaptive design and an item-response model. See the [College Board scoring explanation](https://satsuite.collegeboard.org/scores/what-scores-mean/how-scores-calculated).

In **Admin → Test Management → SAT score conversion**, an admin enters one comma-separated row per section. Values begin at 200, end at 800, are multiples of 10, and never decrease. Saving publishes a new revision for that form. A session pins its revision and question snapshot when opened. When editors change the number of questions, the form needs a matching conversion before new sessions can start. An unconfigured diagnostic still returns raw results. Previously completed attempts keep their original results.

The finish RPC grades and updates the same attempt row under its existing row lock. Review reads that row by ID and checks ownership. The URL holds the attempt ID for refresh and history navigation. Active time excludes recorded fullscreen pauses. Topic reports aggregate the original question metadata from the attempt snapshot, so later edits do not change past reports.
